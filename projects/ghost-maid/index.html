Ghost Maid

Ghost Maid is a playful room-cleaning game in which players use a set of unusual tools to clean spaces and interact with mischievous ghosts. The project was created collaboratively during Carnegie Mellon’s National High School Game Academy.

The Experience

Players switch between tools including a trash bag, blow dryer, scrubber, and magnifying glass. Each tool changes how the player interacts with objects and ghosts in the environment, creating a tactile, playful cleaning experience.

My Role

I collaborated with a multidisciplinary student team on the game’s visual design, production, and interactive experience. The original installation was designed for CMU ETC’s physical board interface and was later adapted for browser play using mouse and keyboard controls.

Web Adaptation

The original game used physical tagged objects on an ETC interactive board. For the web version, the interaction system was adapted so players can select tools with the keyboard and use them through normal mouse input, making the project accessible without specialized hardware.
