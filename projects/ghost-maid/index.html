The Experience

Players switch between tools including a trash bag, blow dryer, scrubber, and magnifying glass. Each tool changes how the player interacts with objects and ghosts in the environment, creating a tactile, playful cleaning experience.

My Role

I served as the producer and artist on a multidisciplinary team, working across visual development, game design, and production while collaborating with teammates on implementation and iteration. I coordinated progress across disciplines, kept teammates accountable to milestones, and helped the team deliver the game on time as a polished and enjoyable playable experience.

Web Adaptation

The original game was designed for CMU ETC’s physical board interface. After the program, I updated the code and input system to adapt the game for browser play using standard mouse and keyboard controls.
